# QR Code Generator 📱🔳

A simple and user-friendly QR Code Generator that allows users to create custom QR codes for various data types, including URLs, phone numbers, emails, Wi-Fi access, and GPS locations.The generated QR codes can be downloaded in PNG format for easy sharing and printing.

## Features & Technologies
- * Choose from multiple QR code sizes (200-500).
- * Supports various data types: URL, phone number, email, Wi-Fi access, and GPS location.
- * Download QR codes in PNG format and Responsive design for mobile and desktop.
- * Built with HTML, CSS, and JavaScript.

## Installation and Usage

1.Clone the repo:
```sh
    git clone https://github.com/OV111/QR-code-generator.git
    cd QR-code-generator
```
2.Open the `index.html` file in your browser to use the QR Code Generator.
